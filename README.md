🎯 Project Description

This project represents the development of a drone web shop.
The web shop allows users to browse all available drones, view discounts, add products to the shopping cart, and see cart details.

An Administration panel, visible only to admin users, enables adding, editing, and deleting individual entities. It is also possible to assign multiple discounts to a single drone, with all discounts being cumulative.

The application includes user registration and login, uses token-based authentication, implements custom routes, CRUD operations, and a RESTful API.
Passwords are securely hashed, and a custom pipe is used to format dates when displaying drone manufacturing dates and when handling discount forms.
